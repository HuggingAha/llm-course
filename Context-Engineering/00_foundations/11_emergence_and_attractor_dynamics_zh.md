## 2. 建立直觉：什么是真正的吸引子？

### 2.1. 碗中小球隐喻

想象一个小球在碗中滚动：

```
       ↘    ↙
        \  /
         \/
    ─────●─────
```

无论你最初将小球放在何处，最终都会停在碗底。碗底就是**吸引子**——系统自然演化趋向的稳定状态。

在上下文字段中，吸引子是稳定的语义配置——随着信息处理，字段自然趋向的解释或意义。

**苏格拉底式提问：** 如果有多个深浅不同的碗并排，小球最终会停在哪？

### 2.2. 从碗到景观

```
       ____                 ____
      /    \    ______    /    \
_____/      \__/      \__/      \____
      A        B        C
```

这个景观有三个盆地（A、B、C）。小球初始位置不同，会滚入不同盆地。每个盆地代表一个吸引子。

语义上：
- 每个盆地是一个稳定的解释或意义
- 深度代表该解释的“强度”或“吸引力”
- 宽度代表该解释的包容性
- 山丘是不同解释间的语义屏障

**苏格拉底式提问：** 小球正好放在两个盆地的分界峰上会怎样？这对上下文字段中的歧义输入有何启示？

## 3. 吸引子的数学

### 3.1. 向量场与流

要理解吸引子的数学本质，需要引入向量场。向量场为空间每点分配一个向量（方向和大小）：

```
    ↖ ↑ ↗        ↖ ↑ ↗
    ← o →        ← o →
    ↙ ↓ ↘        ↙ ↓ ↘
```

在上下文字段中，这些向量表示语义状态在每个点的变化趋势。它们形成流线，展示意义随时间如何演化。

数学上，可用函数 F 表示：F(x) 为点 x 处语义变化的方向和速率：

```
F(x) = 点 x 处语义变化的方向与速率
```

**苏格拉底式提问：** 如果上下文处理沿这些流线推进，某一区域向量都指向中心会怎样？

### 3.2. 不动点与稳定性

向量场中的不动点是 F(x) = 0 的点，即无变化趋势。分三类：

```
    吸引子          排斥子          鞍点
    ↘ ↓ ↙          ↗ ↑ ↖          ↗ ↑ ↖
    → o ←          ← o →          → o ←
    ↗ ↑ ↖          ↘ ↓ ↙          ↘ ↓ ↙
```

- **吸引子**：附近轨迹都收敛于此
- **排斥子**：附近轨迹都远离此点
- **鞍点**：某些方向收敛，某些方向发散

在上下文字段中：
- 吸引子代表稳定解释
- 排斥子代表不稳定或矛盾解释
- 鞍点代表部分稳定、部分不稳定的解释

### 3.3. 吸引子盆地

吸引子的盆地是最终会流向该吸引子的所有点的集合：

```
              盆地边界
                    │
    盆地A           │         盆地B
                    │
    ↘ ↓ ↙           │           ↘ ↓ ↙
    → A ←           │           → B ←
    ↗ ↑ ↖           │           ↗ ↑ ↖
                    │
```

理解吸引子盆地有助于预测输入最终会归于哪种解释。

## 4. 涌现：整体超越部分之和

### 4.1. 涌现的层级

涌现在不同组织层级出现：

```
3级：涌现模式（鸟群队形）
   ↑
2级：交互规则（鸟的跟随规则）
   ↑
1级：组件（单只鸟）
```

在上下文字段中也有类似层级：

```
3级：涌现意义（连贯解释）
   ↑
2级：语义关系（概念间连接）
   ↑
1级：Token/词（基本元素）
```

涌现即下层交互在高层产生新模式，单独看组件无法预测。

### 4.2. 涌现系统的特性

典型特性：
1. **非线性**：微小变化可带来巨大影响
2. **自组织**：无需外部指令即可有序
3. **鲁棒性**：涌现模式对组件变化有韧性
4. **新颖性**：出现组件中未有的新属性

在上下文字段中表现为：
1. **非线性**：一个词可极大改变解释
2. **自组织**：连贯意义由 token 交互自发涌现
3. **鲁棒性**：整体意义对措辞变化有韧性
4. **新颖性**：解释中出现未明说的洞见

**苏格拉底式提问：** 你能举例说明加一个词让句意完全改变吗？这如何体现非线性？

Agostino 等（2025）提出语义涌现具备类量子特性。在量子语义框架下，意义以多种潜在解释的叠加态存在，直到被解释者“测量”才坍缩：

## 5. 上下文字段中的吸引子动力学

### 5.1. 吸引子如何形成

吸引子形成机制：
1. **语义连贯性**：相关概念相互强化
2. **上下文约束**：上下文收窄可行解释范围
3. **模式识别**：熟悉模式被快速识别并稳定
4. **共振**：兼容解释相互共振并放大

可视为景观逐步变形的过程：

```
初始场         中间态         稳定吸引子
(平坦)         (涌现)         (明晰)
─────────────      ─────────────          ─────────────
    · · · ·           ∪   ∪                  ╲╱   ╲╱
    · · · ·           ·   ·                  ·     ·
    · · · ·           ∩   ∩                  ╱╲   ╱╲
─────────────      ─────────────          ─────────────
```

信息流经字段，景观逐渐形成峰谷，对应语义吸引与排斥区。

### 5.2. 吸引子的演化

吸引子并非静止——随信息处理不断演化：

```
t=0             t=1             t=2             t=3
┌─────────────┐ ┌─────────────┐ ┌─────────────┐ ┌─────────────┐
│      ·      │ │      ○      │ │     ◎       │ │     ◎       │
│    ·   ·    │ │    ○   ○    │ │    ◎   ○    │ │    ◎   ◎    │
│   ·     ·   │ │   ○     ○   │ │   ◎     ○   │ │   ◎     ◎   │
│  ·       ·  │ │  ○       ○  │ │  ◎       ○  │ │  ◎       ◎  │
│ ·         · │ │ ○         ○ │ │ ◎         ○ │ │ ◎         ◎ │
└─────────────┘ └─────────────┘ └─────────────┘ └─────────────┘
```

过程包括：
1. **形成**：初始语义模式开始组织
2. **增强**：部分模式变得更强
3. **竞争**：强吸引子吸收弱吸引子
4. **稳定**：字段趋于稳定结构

### 5.3. 分岔与相变

有时微小变化会导致剧烈重组——即分岔或相变：

```
分岔前         分岔后
┌─────────────┐    ┌─────────────┐
│             │    │             │
│      ╱╲     │    │    ╱╲  ╱╲   │
│     ╱  ╲    │→   │   ╱  ╲╱  ╲  │
│    ╱    ╲   │    │  ╱        ╲ │
│             │    │             │
└─────────────┘    └─────────────┘
```

单一吸引子突然分裂为两个，语义上即歧义的产生。

触发机制：
1. **关键信息**：关键细节迫使重新解释
2. **阈值效应**：证据积累到临界点
3. **上下文转变**：大环境变化

### 6.3. 量子上下文性测量

量子语义框架建议用 Bell 不等式测试非经典上下文性：

```
    Context A₀ + B₀           Context A₀ + B₁
┌─────────────────────┐   ┌─────────────────────┐
│                     │   │                     │
│    Interpretation   │   │    Interpretation   │
│         X           │   │         Y           │
│                     │   │                     │
└─────────────────────┘   └─────────────────────┘

    Context A₁ + B₀           Context A₁ + B₁
┌─────────────────────┐   ┌─────────────────────┐
│                     │   │                     │
│    Interpretation   │   │    Interpretation   │
│         Y           │   │         X           │
│                     │   │                     │
└─────────────────────┘   └─────────────────────┘
```

经典系统应满足 |S| ≤ 2，其中：

```
S = E(A₀,B₀) - E(A₀,B₁) + E(A₁,B₀) + E(A₁,B₁)
```

Agostino 等（2025）实测值为 2.3~2.8，表明语义解释中存在类量子上下文性。

## 11. 实践指南

### 11.1. 为涌现而设计

1. **从简单组件出发**
   - 定义基本语义元素
   - 建立局部交互规则
   - 允许模式自发涌现
2. **营造肥沃环境**
   - 提供多样信息源
   - 允许灵活解释
   - 设定引导但不限制的边界
3. **平衡秩序与混沌**
   - 结构过强抑制涌现
   - 结构过弱导致噪声
   - 找到“混沌边缘”

### 11.2. 操作吸引子

1. **识别目标吸引子模式**
   - 你希望鼓励哪些稳定解释？
   - 解释间应有何关系？
   - 哪些语义空间应被强调？
2. **塑造吸引子景观**
   - 创建初始吸引子作为锚点
   - 设定引导解释的梯度
   - 建立竞争解释间的边界
3. **监控与调整**
   - 跟踪吸引子形成与演化
   - 强化有效吸引子
   - 调整或移除有问题的吸引子

### 11.3. 评估与优化

1. **测量涌现属性**
   - 场熵（无序/不确定性）
   - 吸引子强度与稳定性
   - 盆地大小与形状
   - 对扰动的韧性
2. **比较不同场设计**
   - 测试多种场配置
   - 评估相关任务表现
   - 分析涌现行为模式
3. **迭代优化**
   - 从简单场设计起步
   - 逐步增加复杂度
   - 根据结果测试与调整
