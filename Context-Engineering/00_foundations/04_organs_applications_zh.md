# 器官：多智能体系统与应用

> “整体大于部分之和。”——亚里士多德

## 从细胞到器官

我们的旅程已经从**原子**（单条提示）到**分子**（带示例的提示），再到**细胞**（对话记忆）。现在我们来到**器官**——多个上下文细胞协同工作的系统，能够完成单一上下文无法胜任的复杂任务。

```
                      ┌─────────────────────────────────┐
                      │             器官                │
                      │                                 │
   ┌───────────┐      │    ┌─────┐       ┌─────┐       │
   │           │      │    │细胞 │◄─────►│细胞 │       │
   │  输入     │─────►│    └─────┘       └─────┘       │
   │           │      │       ▲             ▲          │
   └───────────┘      │       │             │          │      ┌───────────┐
                      │       ▼             ▼          │      │           │
                      │    ┌─────┐       ┌─────┐       │─────►│  输出     │
                      │    │细胞 │◄─────►│细胞 │       │      │           │
                      │    └─────┘       └─────┘       │      └───────────┘
                      │                                 │
                      └─────────────────────────────────┘
```

就像生物器官由专门细胞协同组成一样，我们的上下文“器官”通过多个 LLM 细胞的编排，解决单一上下文无法完成的问题。

## 为什么需要器官：单一上下文的局限

即使最复杂的上下文细胞也有固有限制：

```
┌─────────────────────────────────────────────────────────────────┐
│ 单一上下文的局限                                                │
├─────────────────────────────────────────────────────────────────┤
│ ✗ 上下文窗口大小受限                                            │
│ ✗ 无法并行处理                                                  │
│ ✗ 只有单一视角/推理方式                                         │
│ ✗ 工具调用能力有限                                              │
│ ✗ 复杂度上限（推理深度）                                        │
│ ✗ 单点故障                                                      │
└─────────────────────────────────────────────────────────────────┘
```

器官通过专精化、并行化和编排克服这些限制。

一个上下文器官包含几个关键组件：

```
│  ┌─────────────────┐                                                      │

│         │   ▲                                                             │
│         │   │                                                             │

│  ┌─────────────────────────────────────────────────────────────────────┐ │
│  │                                                                     │ │

│  │  │             │    │             │    │             │             │ │

│                                                                           │
└───────────────────────────────────────────────────────────────────────────┘
```

让我们逐一介绍各组件：

### 1. 编排器

编排器是器官的“大脑”，负责：

```
┌───────────────────────────────────────────────────────────────┐
│ 编排器职责                                                   │
├───────────────────────────────────────────────────────────────┤
│ ◆ 任务分解                                                   │
│ ◆ 细胞选择与排序                                             │
│ ◆ 信息路由                                                   │
│ ◆ 冲突解决                                                   │
│ ◆ 进度监控                                                   │
│ ◆ 输出整合                                                   │
└───────────────────────────────────────────────────────────────┘
```

编排器可以是：
- **规则驱动**：遵循预设流程
- **LLM 驱动**：用 LLM 本身进行协调
- **混合型**：结合固定规则与动态适应

### 2. 共享记忆

器官的记忆系统让信息在细胞间流动：

```
┌───────────────────────────────────────────────────────────────┐
│ 共享记忆类型                                                 │
├───────────────────────────────────────────────────────────────┤
│ ◆ 工作记忆：当前任务状态与中间结果                           │
│ ◆ 知识库：事实、检索信息、参考资料                           │
│ ◆ 过程日志：操作与推理历史                                   │
│ ◆ 输出缓冲区：综合结果与结论                                 │
└───────────────────────────────────────────────────────────────┘
```

在器官中，记忆管理更为关键，因为总信息量远超单一上下文窗口。

### 3. 专家细胞

器官中的每个细胞都有专门角色：

```
╭──────────────────────────╮   ╭──────────────────────────╮   ╭──────────────────────────╮

│                          │   │                          │   │                          │
│ 角色：信息收集与整合     │   │ 角色：分析、推理、得结论 │   │ 角色：评估质量、查错     │
│                          │   │                          │   │                          │
│ 上下文：搜索结果、知识库 │   │ 上下文：事实、相关信息、 │   │ 上下文：主张、输出、证据 │
│                          │   │ 规则                     │   │                          │
╰──────────────────────────╯   ╰──────────────────────────╯   ╰──────────────────────────╯

╭──────────────────────────╮   ╭──────────────────────────╮   ╭──────────────────────────╮
│    🛠️ 工具用户           │   │    🖋️ 撰写者             │   │    🗣️ 用户接口           │
│                          │   │                          │   │                          │
│ 角色：调用外部工具、API  │   │ 角色：生成清晰、优美内容 │   │ 角色：与用户交互、澄清   │
│                          │   │                          │   │                          │
```

这些只是示例——细胞可针对任何任务或领域专精化。

## ReAct：基础器官模式

最强大的器官模式之一是 ReAct（推理+行动）：

```
┌───────────────────────────────────────────────────────────────────────────┐
│                                                                           │
│                            ReAct 模式                                      │
│                                                                           │
│  ┌─────────────┐      ┌─────────────┐      ┌─────────────┐               │
│  │             │      │             │      │             │               │
│  │  思考       │─────►│   行动      │─────►│  观察       │─────┐         │
│  │             │      │             │      │             │     │         │
│  └─────────────┘      └─────────────┘      └─────────────┘     │         │
│        ▲                                                        │         │
│        └────────────────────────────────────────────────────────┘         │
│                                                                           │
└───────────────────────────────────────────────────────────────────────────┘
```

每轮循环包括：
1. **思考**：推理当前状态并决定行动
2. **行动**：执行工具、API 调用或信息检索
3. **观察**：接收并解释结果
4. 重复，直到任务完成

该模式实现了推理与工具调用的强大结合。

## 简单器官实现

以下是一个包含三个专用细胞的顺序器官实现示例：

```python
class ContextOrgan:
    """一个包含多个专用细胞的简单上下文器官。"""
    
    def __init__(self, llm_service):
        """用 LLM 服务初始化器官。"""
        self.llm = llm_service
        self.shared_memory = {}
        # 初始化专用细胞
        self.cells = {
            "researcher": self._create_researcher_cell(),
            "reasoner": self._create_reasoner_cell(),
            "writer": self._create_writer_cell()
        }
    
    def _create_researcher_cell(self):
        """创建信息收集专用细胞。"""
        system_prompt = """You are a research specialist. \
        Your job is to gather and organize relevant information on a topic.\
        Focus on factual accuracy and comprehensive coverage.\
        Structure your findings clearly with headings and bullet points."""
        return {
            "system_prompt": system_prompt,
            "memory": [],
            "max_turns": 3
        }
    
    def _create_reasoner_cell(self):
        """创建分析推理专用细胞。"""
        system_prompt = """You are an analytical reasoning specialist.\
        Your job is to analyze information, identify patterns, and draw logical conclusions.\
        Consider multiple perspectives and evaluate the strength of evidence.\
        Be clear about your reasoning process and any assumptions you make."""
        return {
            "system_prompt": system_prompt,
            "memory": [],
            "max_turns": 3
        }
    
    def _create_writer_cell(self):
        """创建内容生成专用细胞。"""
        system_prompt = """You are a writing specialist.\
        Your job is to create clear, engaging, and well-structured content.\
        Adapt your style to the target audience and purpose.\
        Focus on clarity, coherence, and proper formatting."""
        return {
            "system_prompt": system_prompt,
            "memory": [],
            "max_turns": 3
        }
    
    def _build_context(self, cell_name, input_text):
        """为指定细胞构建上下文。"""
        cell = self.cells[cell_name]
        context = f"{cell['system_prompt']}\n\n"
        # 添加共享记忆内容
        if cell_name in self.shared_memory:
            context += f"共享记忆：{self.shared_memory[cell_name]}\n\n"
        # 添加输入文本
        context += f"输入：{input_text}\n"
        return context
    
    def _update_memory(self, cell_name, user_input, output):
        """更新细胞记忆。"""
        cell_memory = self.cells[cell_name]["memory"]
        cell_memory.append({"输入": user_input, "输出": output})
        # 限制记忆长度
        if len(cell_memory) > self.cells[cell_name]["max_turns"]:
            cell_memory.pop(0)
    
    def _route_message(self, cell_name, message):
        """路由消息到指定细胞。"""
        cell = self.cells[cell_name]
        # 这里可以添加更复杂的路由逻辑
        return cell["system_prompt"] + "\n\n" + message
    
    def _resolve_conflict(self, cell_name, output):
        """解决细胞间冲突。"""
        # 简单示例：选择第一个细胞的输出
        return output[0]
    
    def process(self, input_text):
        """处理输入文本。"""
        # 1. 任务分解：假设为三个步骤
        steps = ["research", "reason", "write"]
        results = {}
        
        for step in steps:
            if step == "research":
                cell_name = "researcher"
            elif step == "reason":
                cell_name = "reasoner"
            else:
                cell_name = "writer"
            
            # 2. 细胞选择与排序：此处简化为固定顺序
            
            # 3. 信息路由：为细胞构建上下文
            context = self._build_context(cell_name, input_text)
            
            # 4. 冲突解决：无冲突示例
            
            # 5. 进度监控：此处省略
            
            # 6. 输出整合：收集结果
            output = self.llm.generate(context)
            results[step] = output
            
            # 更新记忆
            self._update_memory(cell_name, input_text, output)
        
        # 返回综合结果
        return " ".join(results.values())
```

该示例展示了一个简单的上下文器官如何实现，包括细胞创建、上下文构建、记忆更新和信息处理等核心功能。
